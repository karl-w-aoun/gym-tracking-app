# GymTrack

Private local-first gym tracker.

## GitHub Pages
Upload this repository to GitHub, then enable **Settings → Pages → Deploy from branch → main / root**. The app is static and needs no backend.

## APK
The easiest path is to package the same web app with **Capacitor** on GitHub Actions. The repository can build an Android APK automatically after a push.

Important: browser localStorage is local to the installed app/browser. Use the built-in Export Backup button regularly.
